Preview paste

Try a CMS paste on the real vpm.org page before you save it. The preview shows only in your own tab, and refreshing the page brings the live version back.

Drag this to your bookmarks bar:

Preview paste

Each time

  1. Copy the paste. For the voter guide header, run vgcopy.
  2. Open the live page, for example vpm.org/voterguide.
  3. Click Preview paste. The first time, Chrome asks to let vpm.org see your clipboard. Click Allow.

If the clipboard is blocked, a box opens so you can paste by hand. Your clipboard still holds the paste afterward, so it's ready for the CMS.

The bookmark swaps the live block whose classes match the paste's first element. To replace a different element, use the console route in the README.
