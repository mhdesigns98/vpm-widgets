# Un-Wine'd — Episode + Sponsors

The upper section of the Un-Wine'd page: "Stream more" lockup, in-page jump links, the PBS
viral player, the episode write-up, and the sponsor row.

**Uses widget:** `links-with-map` (vpm-widgets) — sits directly below this block on the same page.
This page supplies the anchor targets its jump links point at; see *Page assembly* below.

That widget lives in `widgets/links-with-map/` because
it's reusable — the wineries directory is only its first instance. This page carries its own copy of
the markup, per the "Consuming widgets" rule in `CLAUDE.md`. If `links-with-map` changes
upstream, refresh the copy here.

## Per-episode changes

- The player iframe `src` **and its `title`** (the title names the episode; leaving a stale one
  is worse than a generic one).
- `.vpm-unwined__heading` — the episode name.
- The two `.vpm-unwined__body` paragraphs.

Sponsors change per underwriting cycle, not per episode.

## Usage (ACF split-file)

| ACF field | File |
|---|---|
| HTML | `html.html` |
| CSS | `css.css` |

No `js.js` — the block is static.

If you'd rather paste one stylesheet for the whole page instead of one per block, use
`unwined-page.css`, which is this block's CSS plus `links-with-map/css.css`. It's generated by
concatenation, not hand-maintained — regenerate it after editing either block:

```bash
{ cat ~/Projects/vpm/vpm-widgets/pages/unwined-episode/css.css; echo; \
  cat ~/Projects/vpm/vpm-widgets/widgets/links-with-map/css.css; } \
  > ~/Projects/vpm/vpm-widgets/pages/unwined-episode/unwined-page.css
```

Note this reads across `pages/` and `widgets/` — it's a local regeneration step, not a build dependency. The
committed `unwined-page.css` is the artifact; nothing at runtime reaches into `widgets/`.

## Page assembly — the jump-link anchors

`#vineyards` is owned by the **page**, not by either block. Neither block
contains an `id`, so they stay safe to place more than once. Wrap each target block in the page:

```html
<div id="vineyards" style="scroll-margin-top: 96px;"></div>
<!-- links-with-map block goes here -->
```

The `scroll-margin-top` is optional: vpm.org's header isn't sticky, so jump links need no offset
(see `CLAUDE.md`). Leave it in if the header ever becomes sticky.

There is no Recipes jump link, because the page has no recipes section. If one is added, put a
`<a class="vpm-unwined__jump-link" href="#recipes">Recipes</a>` back in the `<nav>` in `html.html`
and wrap the recipes block in `<div id="recipes"></div>`. Never leave a jump link pointing at nothing.

### Paste order (top to bottom of the page)

1. **This block**: `html.html` in the ACF HTML field and `css.css` in the CSS field (or
   `unwined-page.css` once for the whole page, instead of one stylesheet per block).
2. **The anchor wrapper**: `<div id="vineyards" style="scroll-margin-top: 96px;"></div>`, placed
   immediately above the widget so the `#vineyards` jump link lands on the map.
3. **The `links-with-map` widget** (`widgets/links-with-map/html.html` and `css.css`), directly below.

## What changed from the previous version

- **`img { … }` in a page-level `<style>` is gone.** It was a bare element selector, so it
  restyled every image on the page, including site chrome and unrelated blocks. Now scoped to
  `.vpm-unwined .vpm-unwined__sponsor-logo`.
- `.mytable` namespaced away; sponsors are a flex row, not a `<table width="50%">` that couldn't
  reflow on a phone.
- Player iframe has a `title` (WCAG 4.1.2); it had none.
- `rel="noopener noreferrer"` added to all four `target="_blank"` links.
- Episode title `<h3>` → `<h2>`, so it doesn't sit above the `<h2>` in the block below it.
- Unclosed `<p>` closed; `<hr>` and the empty `<p></p>` spacer replaced with real spacing.
- Inline `style` attributes and `font-size: 3rem` replaced with inlined VPM tokens.
- Sponsor logo has `width`/`height` (360×183, its true size — the `x500` in the URL is a cap the
  source doesn't reach) so it no longer shifts layout while loading.
- Sponsor logo `alt` "virginia wine" → "Virginia Wine Board"; it's the link's accessible name.
- Typo: "Saturdays afternoons" → "Saturday afternoons".
