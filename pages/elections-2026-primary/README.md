# Elections 2026 Primary

The 2026 Virginia primary block on VPM's elections page: key dates, a video carousel and links to
coverage. Built for WordPress ACF (split-file).

## Files

| File | Purpose |
|---|---|
| `preview.html` | Full browser preview with CodePen export button |
| `html.html` | Paste into ACF HTML field |
| `css.css` | Paste into ACF CSS field |
| `js.js` | Paste into ACF JS field |

All classes namespaced `vpm-elec26-`.
